这里整理 ZGI 官网文档中心和当前 Mintlify 手册中的主要更新。正式产品版本以发布公告、仓库标签或部署包版本为准。

## v2026.04 重点功能更新

- **知识库与 RAG 增强**：补充知识库从文档导入、解析清洗、向量化索引、检索重排到引用溯源的完整链路说明，强化 Top K、分数阈值、Rerank、Embedding 和图谱召回配置指引。
- **知识图谱能力完善**：新增知识图谱增强检索说明，覆盖实体抽取、关系建模、跨文档关联和图遍历推理，面向合同、制度、法务合规等关联型问答场景。
- **工作流 API 扩展**：补充工作流外部调用、流式响应事件、阻塞式响应、会话上下文、文件上传和错误码说明，便于接入 Web 应用、企业微信/飞书机器人、OA 和工单系统。
- **模型网关治理升级**：完善 Provider、Model、Channel、API Key、Default Model 和 Billing 等关键构成说明，补充通道路由、连通性测试、额度控制和调用追踪能力。
- **数据库与 NL2SQL 补充**：扩展结构化数据库能力说明，包括 AI 生成表结构、数据导入、自然语言查询、复杂计算、操作日志和智能体工作流联动。
- **权限、成本与审计补充**：完善工作区角色、API Key 权限、额度预算、Token 用量归因、账单流水和审计日志说明，支持企业级治理落地。
- **知识库演示视频上线**：在知识库页面新增“1 分钟搭建知识库”演示视频，并配置封面图，帮助用户快速理解知识库搭建流程。
