# 更新日志

这里整理 ZGI 官网文档中心和当前 Mintlify 手册中的主要更新。正式产品版本以发布公告、仓库标签或部署包版本为准。

## v2026.03

- 新增企业本体知识图谱规划，用于定义企业实体和关联关系。
- 新增 OpenClaw 融合能力规划。
- 自建 OCR 引擎完成技术调研并立项。
- 模型网关新增 DeepSeek-R1、Gemini 1.5 Flash 等模型接入说明。
- 权限系统补充 API Key 级 IP 白名单能力说明。

## v2025.12

- 知识图谱增强检索上线，用于提升关联型问题召回。
- 工作流画布重构，增加循环节点和并行执行能力。
- SSO 增加飞书、钉钉 OAuth 2.0 接入说明。
- Token 成本归因可精确到应用级别。

## v2025.09

- NL2SQL 自然语言查数据库能力上线。
- 私有化部署增加 Kubernetes Helm Chart 安装路径。
- Python SDK 和 JavaScript SDK 进入正式发布说明。
- 官网文档中心标注 SOC 2 Type II 认证通过。

- 更新安全与合规页，增加官网标注的合规状态和发布前核验说明。
