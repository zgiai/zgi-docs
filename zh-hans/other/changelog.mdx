这里整理 ZGI 官网文档中心和当前 Mintlify 手册中的主要更新。正式产品版本以发布公告、仓库标签或部署包版本为准。

## v2026.04 重点功能更新

- 知识库与 RAG 增强：补充文档导入、解析清洗、向量化索引、检索重排到引用溯源的完整链路说明。
- 知识图谱能力完善：新增知识图谱增强检索说明，覆盖实体抽取、关系建模、跨文档关联和图遍历推理。
- 工作流 API 扩展：补充外部调用、流式响应、阻塞式响应、会话上下文、文件上传和错误码说明。
- 模型网关治理升级：完善 Provider、Model、Channel、API Key、Default Model 和 Billing 等关键构成说明。
- 数据库与 NL2SQL 补充：扩展结构化数据库能力、数据导入、自然语言查询、复杂计算和操作日志说明。
- 权限、成本与审计补充：完善工作区角色、API Key 权限、额度预算、Token 用量归因、账单流水和审计日志说明。
- 知识库演示视频上线：在知识库页面新增“1 分钟搭建知识库”演示视频，并配置封面图。

## v2026.03

- 新增企业本体知识图谱规划，用于定义企业实体和关联关系。
- 新增 OpenClaw 融合能力规划。
- 自建 OCR 引擎完成技术调研并立项。
- 模型网关新增 DeepSeek-R1、Gemini 1.5 Flash 等模型接入说明。
- 权限系统补充 API Key 级 IP 白名单能力说明。
