# 数据库

ZGI 的完整产品栈会使用多类数据存储。不同存储承担不同职责：关系型数据库保存业务数据，缓存系统支撑会话和队列，向量索引用于知识检索。

## 主要数据类型

- 用户、工作区和权限数据
- 智能体、工作流和模型配置
- 知识库文档、切片和元数据
- 向量索引和检索数据
- 模型调用日志和运行记录
- 审计日志和成本统计

## 本地开发模式

在 `zgi-pre` 的完整本地环境中，PostgreSQL 和 Redis 由顶层 Docker 栈统一提供。各服务通过环境变量连接到共享基础设施，避免重复启动多套中间件。

## 生产部署建议

生产环境应根据数据规模和安全要求独立规划数据库、备份、监控和访问策略。对于知识库和审计数据，建议明确保留周期和恢复方案。
