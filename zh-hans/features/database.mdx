# 数据库

ZGI 数据库不是简单的数据存储模块，而是面向业务智能场景的结构化数据能力底座。它可以从文档、表格或业务说明中生成表结构，并把数据查询、统计分析、复杂计算、操作日志和智能体问答串联起来。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 表结构设计 | 支持字段定义、数据类型、必填规则和人工调整 |
| 智能生成表结构 | 根据业务文档、表格或描述自动推荐字段 |
| 数据导入 | 将结构化数据批量写入业务表 |
| 数据查询 | 支持精确查询、条件筛选、模糊匹配和聚合统计 |
| 自然语言查询 | 将中文问题转换为 SQL 并返回业务化回答 |
| 操作日志 | 记录 SQL、状态、用户、时间和错误信息 |
| 智能体联动 | 作为工作流数据源或计算节点使用 |

## 支持的数据类型

| 类型 | 用途 | 示例 |
| --- | --- | --- |
| `text` | 文本 | 名称、地址、描述 |
| `numeric` | 精确数值 | 金额、费率、价格 |
| `integer` | 整数 | 数量、天数、序号 |
| `timestamp` | 时间 | 合同日期、操作时间 |
| `boolean` | 布尔 | 是否启用、是否完成 |

## 表结构设计

简单场景可以使用单表，例如员工台账、设备清单或项目列表。复杂场景建议使用多表，例如：

- 主表：保存合同编号、金额、甲方、乙方、开始时间等核心字段。
- 条款表：保存付款、违约、续约、终止等原文条款。
- 规则表：保存计算标准、业务规则和判断条件。
- 明细表：保存多条记录、分期付款或变更历史。

## 智能生成表结构

用户可以上传业务材料并填写需求说明，系统根据内容推荐字段名称、字段描述、数据类型、必填字段和主键标识。

适合场景：

- 不熟悉数据建模，需要快速起步。
- 已有合同、台账或表格，但尚未整理成数据库。
- 需要快速搭建演示数据模型。
- 希望把文档内容转成可查询的结构化数据。

智能生成适合做初稿，关键字段命名、拆分粒度和业务主键仍建议由业务或实施人员确认。

## 数据导入与维护

表结构确定后，可以将业务数据导入表中。建议先少量导入，验证查询和字段设计合理后，再分批导入更多数据。

## 自然语言查询

业务人员可以直接用中文提问，系统将问题转换为 SQL，执行后再返回自然语言答案。

```text
用户提问：阳光公司的物业费支付方式是什么？

系统生成 SQL：
SELECT payment_method FROM contracts WHERE company_name = '阳光公司';

返回结果：
阳光公司的物业费支付方式为“季度预付”。
```

## 查询与计算能力

| 查询类型 | 说明 | 示例 |
| --- | --- | --- |
| 精确查询 | 定位单条记录 | 查询某公司的合同信息 |
| 条件筛选 | 过滤多条记录 | 查询本月到期合同 |
| 模糊匹配 | 关键词搜索 | 查询包含“物业”的项目 |
| 聚合统计 | 汇总、计数、排序 | 统计每栋楼年租金 |
| 多表联查 | 跨表关联查询 | 合同主表和条款表联合查询 |
| 复杂计算 | 多字段规则计算 | 计算违约金或付款周期 |

## 操作日志

数据库模块应记录操作时间、操作类型、执行状态、操作表、操作用户和实际 SQL。日志可用于查询报错排查、提示词优化复盘、业务数据修改追踪和智能体结果异常定位。

## 典型场景

- 合同管理
- 项目台账
- 经营数据统计
- 物业费用计算
- HR 信息查询
- 设备资产管理
