# 智能体编排

智能体编排用于把模型、工具、知识库和业务流程组合成可执行的任务单元。它让智能体不只是回答问题，还能按步骤完成检索、判断、调用工具和生成结果。

## 智能体由什么组成

一个智能体通常包含：

- 角色和任务说明
- 可访问的知识库
- 可调用的工具
- 模型和参数配置
- 输入输出约束
- 运行日志和错误处理策略

## 编排方式

ZGI 支持把复杂任务拆成多个步骤。每个步骤可以由模型判断，也可以通过固定流程约束。这样既保留模型的灵活性，也能让关键业务流程更稳定。

## 工具调用

智能体可以调用内部工具、插件服务或外部 API。对高风险工具，建议配置权限范围、调用审计和人工确认节点。

## 常见场景

- 客服工单处理
- 资料检索和报告生成
- 数据分析助手
- 内部流程自动化
- 多步骤研发辅助任务
