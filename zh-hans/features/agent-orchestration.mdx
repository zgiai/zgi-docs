## 什么是智能体

智能体是 ZGI 的最小交付单元，是用户最终发布、调用和集成的 AI 应用。一个智能体由**工作流 + 模型 + 知识库 + 提示词**组合而成，对外提供对话式或工作流式的 AI 能力。

## 两种智能体类型

| 类型 | 描述 | 典型场景 |
| --- | --- | --- |
| **对话型智能体** | 直接与用户对话，基于知识库和模型回答问题 | 客服、问答、咨询 |
| **工作流型智能体** | 按照预设工作流执行多步骤任务 | 合同审核、报表生成、数据分析 |

## 智能体生命周期

### 创建

选择智能体类型，配置基础信息：名称、图标、描述、权限范围（仅自己可见 / 团队可见 / 组织可见）。系统自动生成唯一标识符，并初始化工作流草稿。

### 编排

在可视化画布上拖拽节点搭建业务流程。支持模型节点、知识库节点、数据库节点、HTTP 节点、代码节点、条件分支、循环、迭代等多种节点类型。

### 调试

在调试区输入测试数据，系统通过 SSE 实时展示各节点的执行状态与结果。草稿每 30 秒自动保存，避免编辑丢失。

### 发布

一键发布为可访问的 Web 应用（智能体落地页），或生成 API Key 供外部系统调用。每次发布自动生成版本号，可追溯、可回滚。

### 运维

查看运行日志、Token 消耗、调用次数、异常率等运行数据。支持配置 API Key 的额度上限、过期时间、IP 白名单。

## 工作流节点类型

ZGI 提供丰富的内置节点，覆盖大多数业务流程编排需求：

| 节点 | 功能 | 典型用法 |
| --- | --- | --- |
| **开始节点** | 定义工作流输入参数 | 接收用户输入或 API 请求参数 |
| **LLM 节点** | 调用大模型进行推理 | 文本生成、分析、翻译、分类 |
| **知识库节点** | 从知识库检索信息 | 问答、条款查询、带引用回答 |
| **数据库节点** | 查询结构化数据 | 合同台账、项目记录、数据统计 |
| **NL2SQL 节点** | 自然语言转 SQL | 业务人员查数据库不需要写 SQL |
| **条件分支** | 根据变量值选择执行路径 | 风险等级分流、类型判断 |
| **代码节点** | 运行 Python / JS 自定义逻辑 | 数据处理、格式转换 |
| **HTTP 节点** | 调用外部 API | 对接 CRM、ERP、OA 等系统 |
| **迭代节点** | 对数组数据批量处理 | 逐份合同审核、逐条数据处理 |
| **循环节点** | 按条件重复执行 | 重试逻辑、迭代式优化 |
| **结束节点** | 输出最终结果 | 返回 JSON、文本或触发后续动作 |

## 触发方式

| 触发方式 | 说明 | 典型场景 |
| --- | --- | --- |
| 用户对话 | 用户发送消息时触发工作流 | 客服问答、智能助手 |
| API 调用 | 通过 REST API 触发 | 系统集成、自动化流程 |
| 定时任务 | 按 Cron 表达式定期执行 | 定期报表、数据同步 |
| 文件上传 | 用户上传文件时自动触发 | 合同上传自动审核、文档自动入库 |
| Webhook | 接收外部系统回调触发 | OA 审批、CRM 事件、ERP 变更 |

## 变量与上下文

变量是节点间传递数据的核心机制。ZGI 支持三层变量体系：

| 变量类型 | 作用域 | 典型用途 |
| --- | --- | --- |
| **环境变量** | 全局 | API Key、模型配置等敏感信息 |
| **会话变量** | 单次对话 | 上下文记忆、用户偏好 |
| **节点变量** | 节点间传递 | 上一步的输出作为下一步输入 |

## 核心特性

- **SSE 流式执行** — 实时推送每个节点的执行状态与结果，前端可展示进度

- **草稿自动保存** — 每 30 秒自动保存工作流草稿，防止编辑丢失

- **版本管理** — 每次发布自动生成版本号，可追溯、可回滚

- **YAML 模板** — 智能体配置可导出为 YAML，跨团队、跨环境复用

- **API Key 配额** — 为每个智能体生成专属 API Key，支持每日 / 每月配额、过期时间、IP 白名单

- **资产防误删** — 检查机制防止误删正在运行的智能体；员工离职可一键交接
