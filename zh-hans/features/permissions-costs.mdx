# 权限与成本管控

企业级 AI 平台需要同时管住访问权限和使用成本。ZGI 将角色权限、API Key、调用日志、预算上限和成本归因放在同一套治理体系中处理。

## 权限体系

ZGI 使用基于角色的访问控制。不同角色可以访问不同功能和资源。

| 角色 | 权限范围 |
| --- | --- |
| 超级管理员 | 管理所有工作区、账单、权限和私有化部署配置 |
| 工作区管理员 | 管理本工作区成员、预算、应用和资源 |
| 开发者 | 创建和编辑工作流，管理 API Key，查看调用日志 |
| 业务用户 | 使用已发布应用，查看自己的使用记录 |
| 只读成员 | 查看知识库和工作流，不能修改或调用 |

## API Key 管理

API Key 应按系统、应用或集成方分别创建，不建议多个系统共用同一个 Key。生产环境中建议配置：

- 权限范围
- 来源 IP 白名单
- 过期时间
- 调用额度
- 所属工作区或应用

## 成本管控

模型调用会产生 Token 消耗。ZGI 可以按多个维度记录和归因：

- 用户
- 部门或工作区
- 应用
- 智能体或工作流
- 模型
- API Key

## 预算与预警

常见预算策略包括：

- 为工作区设置月度预算。
- 为 API Key 设置调用上限。
- 到达预算 80% 时发送通知。
- 到达预算 100% 时限流或暂停调用。
- 对高成本模型设置单独审批或白名单。

## 审计日志

审计日志应覆盖登录、权限变更、知识库访问、模型调用、工作流发布、API Key 创建和管理员配置变更。对于合规要求较高的场景，日志需要长期保存并支持按用户、时间、资源和操作类型筛选。
