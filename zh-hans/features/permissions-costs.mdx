# 权限与成本管控

企业使用 AI 系统时，需要同时解决两个问题：谁可以使用哪些能力，以及这些能力消耗了多少成本。ZGI 将权限、配额、审计和成本统计放在同一套治理模型中处理。

## 权限模型

权限通常按工作区、角色和资源范围组织。管理员可以控制用户是否能访问知识库、智能体、工作流、模型配置和管理功能。

## 成本统计

模型调用会产生 Token 消耗和费用。ZGI 可以按工作区、用户、应用、智能体或工作流统计调用量，帮助团队识别高成本任务并优化模型选择。

## 配额控制

配额可以用于限制高成本或高风险能力的使用，例如：

- 每日模型调用次数
- 每月 Token 消耗上限
- 单个工作流运行次数
- 特定模型的调用权限
- API Key 的访问范围

## 审计日志

关键操作应保留审计记录，包括用户登录、权限变更、知识库访问、模型调用、工具调用和管理员配置变更。
