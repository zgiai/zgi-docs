# 模型网关

模型网关是 ZGI 统一管理模型调用的入口。上层应用、工作流和智能体只需要调用统一接口，底层可以按配置切换不同模型、不同供应商或私有本地模型。

## 支持的模型来源

| 提供商 | 常见模型 | 适用场景 |
| --- | --- | --- |
| OpenAI | GPT-4o、GPT-4 Turbo、o 系列 | 通用推理、代码、多模态 |
| Anthropic | Claude 3.5 Sonnet、Claude 3 Opus | 长文本分析、合规审阅 |
| DeepSeek | DeepSeek-V3、DeepSeek-R1 | 中文理解、推理和成本敏感场景 |
| 阿里云 | 通义千问 Max、Plus、Turbo | 中文场景和国产化要求 |
| 百度 | 文心一言 | 中文场景和国产化要求 |
| Google | Gemini Pro、Gemini Flash | 多模态和长上下文 |
| 私有模型 | Ollama 兼容模型 | 数据不出域或离线部署 |

## OpenAI 兼容调用

ZGI 网关可以对外暴露 OpenAI 兼容接口。业务代码只需要把 `base_url` 指向 ZGI 网关，底层模型切换由控制台配置完成。

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_ZGI_API_KEY",
    base_url="https://api.zgi.cn/v1"
)

response = client.chat.completions.create(
    model="zgi-default",
    messages=[{"role": "user", "content": "你好"}]
)

print(response.choices[0].message.content)
```

## 路由与降级

模型网关可以根据策略选择模型：

- **按性能路由**：优先选择响应更快的模型。
- **按成本路由**：简单任务使用低成本模型，复杂任务使用旗舰模型。
- **按场景路由**：法务、客服、代码、数据分析等任务绑定不同模型。
- **自动降级**：主模型异常时切换备用模型，降低业务中断风险。
- **负载均衡**：多个 Key 轮询或分组，缓解单 Key 限速问题。

## 成本与审计

网关层可以统一记录 Token 用量、调用方、模型、延迟、错误和费用。后续权限与成本管控可以基于这些日志按工作区、应用、用户或部门做归因分析。
