# 模型网关

模型网关负责统一接入和管理不同模型服务。应用和智能体不需要直接绑定某一个模型厂商，而是通过统一接口调用模型能力。

## 核心能力

- 统一模型调用入口
- 多模型提供商接入
- 模型路由和降级策略
- 请求限流和配额控制
- 调用日志记录
- Token 用量和成本统计

## 为什么需要模型网关

企业通常会同时使用多个模型：通用大模型、私有模型、嵌入模型、视觉模型和语音模型。如果每个业务模块都直接接入模型提供商，后续切换、审计和成本控制都会变得困难。

模型网关把这些差异收敛到统一接口，让上层业务只关注“需要什么能力”，而不是关心“具体调用哪个厂商”。

## 路由策略

常见路由策略包括：

- 按任务类型选择模型
- 按成本优先选择模型
- 按延迟优先选择模型
- 按租户或工作区绑定模型
- 在主模型失败时自动降级到备用模型
