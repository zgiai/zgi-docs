# 工作流

工作流用于把复杂任务拆解成清晰的步骤。每个步骤可以执行模型调用、知识库检索、工具调用、条件判断或人工确认。

## 工作流适合解决什么问题

工作流适合处理需要稳定执行顺序的任务，例如：

- 审批前自动检查材料
- 客服问题分流和回复草稿生成
- 合同或文档摘要
- 数据提取和结构化输出
- 多系统之间的信息同步

## 基本节点

常见节点包括：

- 输入节点
- 模型节点
- 知识库检索节点
- 条件分支节点
- 工具调用节点
- 人工确认节点
- 输出节点

## 智能体与工作流的关系

智能体更适合处理开放任务，工作流更适合处理稳定流程。实际使用时，两者可以结合：工作流负责主流程，智能体负责某些需要判断和生成的步骤。
