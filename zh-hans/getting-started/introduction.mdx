# 什么是 ZGI

ZGI 是面向企业的 AI 运行与管理底座。它把企业内部的数据、文档、模型、工具和流程组织在同一套平台里，让 AI 能力从零散试验变成可运行、可治理、可复用的组织资产。

从能力边界上看，ZGI 不只是一个聊天机器人，也不只是一个模型调用接口。它更像企业 AI 的中间层：向下连接知识库、数据库、模型和执行环境，向上承载智能体、工作流、业务应用和 API 集成。

## 一句话定义

ZGI 是一套企业级 AI 底座，通过知识库、模型网关、智能体编排和工作流，把企业知识、模型能力与业务流程连接起来，形成可控、可追溯、可持续迭代的 AI 应用平台。

## 解决的问题

企业落地 AI 时，常见阻碍不是“没有模型”，而是缺少把模型稳定接入业务的底座。

### AI 资产难以沉淀

很多团队把提示词、工具配置、知识库经验保存在个人电脑或单个项目中。人员变动后，经验难以交接，历史版本也很难追踪。ZGI 将这些配置和流程沉淀到组织级平台，便于复用和管理。

### 回答结果难以信任

大模型直接回答时容易产生幻觉。ZGI 通过知识库检索、知识图谱、多路召回和原文引用，让回答尽量基于企业自己的资料，并保留可核验来源。

### 多模型、多工具和成本难以管控

当不同部门分别采购模型、搭建工具和管理 API Key 时，IT 和管理团队很难统一权限、预算和审计。ZGI 通过统一模型网关和权限成本体系，把调用、日志、预算和访问范围集中治理。

## 核心能力

- **企业级知识库与 RAG**：支持文档解析、语义切分、向量检索、知识图谱增强和原文引用。
- **智能体与工作流编排**：通过节点和流程把模型、工具、知识库、数据库和外部系统串起来。
- **统一模型网关**：集中接入 OpenAI、Claude、DeepSeek、通义千问、文心、Gemini 以及私有本地模型。
- **结构化数据库能力**：支持业务表建模、数据导入、自然语言查询和智能体联动。
- **权限与成本管控**：按工作区、角色、API Key、模型和应用记录权限、调用量和成本。
- **灵活部署**：支持云端使用、私有化部署和混合架构，满足不同数据安全要求。

## 适合谁使用

ZGI 适合正在把 AI 引入业务流程的团队，包括企业信息化部门、研发团队、运营团队、客服团队、法务合规团队、知识管理团队和行业解决方案团队。
