本教程会带你快速跑通 ZGI 的基础流程：准备资料、创建知识库、配置大模型、编排智能体，并发布成一个可使用的 AI 应用。

完成后，你将得到一个**基于企业资料回答问题的智能体**。比如上传合同、制度、手册、FAQ 后，可以直接提问：

- “制度里报销流程怎么走？”
- “某份合同的付款周期和违约金规则是什么？”
- “最近三个月有哪些合同快到期？”

## 你会完成什么

通过本教程，你将完成 4 件事：

1. 导入资料，创建知识库
2. 配置可用的大模型
3. 搭建一个基础知识库问答智能体
4. 发布为外部应用，也就是智能体落地页

建议首次体验时，先选择少量、质量较高的文档，例如 3 到 5 份合同、制度、产品手册或 FAQ。先把基础流程跑通，再逐步增加资料量。

## 开始前准备

开始前，请先准备好以下内容：

- 一批测试资料，例如 PDF、Word、Excel、图片扫描件或 Markdown 文档
- 一个可用的大模型来源，例如平台已有模型、云端模型 API Key，或私有化部署中的本地模型
- 如果使用私有化部署，需要提前准备对应的部署环境

快速开始阶段不需要一开始就理解所有高级能力，建议先从“上传资料 → 检索资料 → 生成回答 → 发布应用”这条最基础路径跑通。

## 第 1 步：导入资料，创建知识库

进入知识库模块后，上传准备好的资料。ZGI 会对文档进行**自动解析、自动切片**，并构建可检索的知识库，方便后续智能体基于这些资料回答问题。

![知识库资料导入示例](/images/quickstart/image1.png)

知识库支持的能力包括：

- 文档自动解析并自动切片
- 向量召回和图谱召回
- Rerank 重排
- TopK、置信阈值、嵌入模型配置

首次测试时建议这样做：

1. 先上传少量高质量文档
2. 等待系统完成解析和切片
3. 使用知识库测试功能进行问答验证
4. 检查召回内容是否准确
5. 确认效果后，再批量导入更多资料

你可以先测试这类问题：

- “制度中请假审批流程是什么？”
- “资料里有没有提到违约金规则？”

如果回答效果不理想，可以重点检查文档质量、切片效果、TopK、嵌入模型、图谱召回和 Rerank 配置。

## 第 2 步：进行大模型配置

![大模型配置示例](/images/quickstart/image2.png)

进入大模型配置模块，选择或接入可用的大模型。

首次体验时，建议先配置能够支撑基础问答的模型，保证知识库问答流程可以顺利跑通。后续可以根据不同任务，再补充适合复杂推理、文本整理、信息抽取等场景的模型。

在实际使用中，大模型主要负责理解用户问题，并结合知识库召回的内容生成最终回答。

## 第 3 步：编排智能体工作流

进入工作流画布，创建一个基础智能体流程。

一个最简单的知识库问答流程可以这样搭建：

![知识库问答工作流示例](/images/quickstart/image3.png)

```text
开始节点 → 知识检索节点 → LLM 节点 → 直接回复节点
```

其中：

- **开始节点**：接收用户输入的问题
- **知识检索节点**：从指定知识库中查找相关内容
- **LLM 节点**：根据用户问题和检索结果生成回答
- **直接回复节点**：把最终结果返回给用户

这些节点都可以根据实际业务自行命名。首次搭建时，建议先保持流程简单，先验证“用户提问后，系统能不能从知识库里找到相关内容，并生成回答”。

如果知识库里有内容，但智能体没有正确回答，可以重点检查：

- 知识检索节点是否选择了正确的知识库
- 知识检索节点是否成功召回内容
- LLM 节点是否正确引用了知识检索节点的输出
- 直接回复节点是否接收到了最终答案

## 第 4 步：调试并发布为外部应用

![应用发布示例](/images/quickstart/image4.png)

工作流搭建完成后，先在调试区进行测试。

建议至少测试 3 类问题：

| 类型 | 示例 |
| --- | --- |
| 精准查询类 | “合同的到期时间是什么？” |
| 总结归纳类 | “帮我总结这份合同的核心条款。” |
| 对比分析类 | “这几份合同的付款周期有什么不同？” |

确认回答稳定后，可以将智能体发布为外部应用，也就是智能体落地页。发布后，用户可以通过落地页直接访问和使用这个智能体。

## 开发者快速调用

开发者也可以通过 API 调用知识库或工作流。典型请求会包含 API Key、用户问题、模型配置和知识库标识，响应中会返回回答内容和引用来源。

```bash
curl -X POST https://api.zgi.cn/v1/chat \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zgi-default",
    "messages": [
      { "role": "user", "content": "查询最近三个月的合同到期情况" }
    ],
    "knowledge_base_id": "kb_xxxxxx"
  }'
```

示例响应：

```json
{
  "id": "msg_xxxxxx",
  "content": "根据知识库检索，以下合同将在三个月内到期...",
  "citations": [
    {
      "source": "采购合同_2025Q4.pdf",
      "page": 3,
      "paragraph": "第五条 合同期限..."
    }
  ]
}
```
