# 快速开始

这页帮助你用最短路径跑通 ZGI：准备资料，创建知识库，接入模型，编排智能体，然后发布为应用或 API。

## 准备工作

开始前建议准备：

- 一个企业邮箱，用于创建账号和工作区。
- 一批需要导入的资料，例如 PDF、Word、Excel、图片扫描件或 Markdown 文档。
- 一个可用模型来源，例如云端模型 API Key、ZGI 共享模型，或私有化部署中的本地模型。
- 如果使用私有化部署，需要准备 Docker 环境或 Kubernetes 集群。

## 选择部署方式

### 云端 SaaS

云端版本适合快速验证和中小团队使用。注册后即可创建工作区、上传文档、配置模型和发布应用，不需要维护底层基础设施。

### 私有化部署

私有化部署适合金融、政企、医疗、教育等对数据边界要求较高的场景。文档解析、OCR、知识库检索、模型调用和日志都可以运行在企业内网中。

### 混合架构

混合架构适合跨区域或大型企业：敏感数据留在内网，部分通用模型调用或非敏感计算走云端，以平衡安全、成本和弹性。

## 四步上线第一个 AI 应用

### 1. 创建工作区

注册账号后创建企业工作区，并邀请团队成员。建议先按部门或业务线划分工作区，便于后续做权限和成本统计。

### 2. 导入数据，构建知识库

将合同、报告、手册、制度、FAQ 或表格上传到知识库。系统会完成解析、切分、向量化和索引构建。首次验证时建议先导入少量高质量文档，确认召回效果后再批量导入。

### 3. 接入模型，配置网关

在模型管理中接入模型 API Key，或选择平台已有模型。推荐先配置默认模型，再按任务类型补充推理模型、低成本模型和嵌入模型。

### 4. 编排智能体并发布

在工作流画布中选择触发器、知识库检索、模型推理、条件分支、工具调用和输出节点。调试通过后，可以发布为 Web 应用、对话入口或 API 端点。

## 开发者快速调用

开发者可以通过 API 调用知识库或工作流。典型请求会包含 API Key、用户问题、模型配置和知识库标识，响应中应包含回答内容和引用来源。

```bash
curl -X POST https://api.zgi.cn/v1/chat \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zgi-default",
    "messages": [
      { "role": "user", "content": "查询最近三个月的合同到期情况" }
    ],
    "knowledge_base_id": "kb_xxxxxx"
  }'
```

```json
{
  "id": "msg_xxxxxx",
  "content": "根据知识库检索，以下合同将在三个月内到期...",
  "citations": [
    {
      "source": "采购合同_2025Q4.pdf",
      "page": 3,
      "paragraph": "第五条 合同期限..."
    }
  ]
}
```
