# 行业场景

ZGI 的能力可以按行业和业务场景组合使用。不同场景对知识库、工作流、模型网关、数据库和智能体的依赖不同。

| 场景 | 能做什么 | 核心能力 |
| --- | --- | --- |
| 合同 / 法务 | 条款提取、风险标注、版本比对、原文溯源 | RAG + 知识图谱 |
| 办公协同 | 会议纪要、周报、制度问答、审批自动化 | 知识库 + 工作流 |
| HR / 档案 | 入职流程、政策问答、员工自助服务 | 知识库 + 智能体 |
| 数据分析 | 用自然语言查询数据库并生成分析结果 | NL2SQL |
| 研发文档 | 技术文档问答、代码说明、新人入门 | RAG + 向量检索 |
| 制造 / 质检 | 工艺参数查询、质检标准比对、段落定位 | RAG + 知识图谱 |
| 政务 / 平台 | 多模型统一接入，下游机构调用统一接口 | 模型网关 |
| 教育 | 学情分析、智能组卷、作文辅导、课堂出题 | 知识库 + 工作流 |

## 选型建议

- 如果核心问题是“资料太多找不到”，优先从知识库开始。
- 如果核心问题是“流程重复但步骤明确”，优先用工作流。
- 如果核心问题是“多个系统需要打通”，重点使用 Webhook 和 API。
- 如果核心问题是“数据都在表里但不会查”，优先使用数据库和 NL2SQL。
- 如果核心问题是“多个模型难管理”，先建设模型网关。
