## 场景总览

| 场景 | 能做什么 | 核心能力 |
| --- | --- | --- |
| **合同 / 法务** | 合同条款提取、风险标注、版本比对，每条结论附原文出处 | 知识图谱 + RAG |
| **办公协同** | 会议纪要整理、周报生成、制度规范问答、审批流程自动化 | 知识库 + 工作流 |
| **HR / 档案** | 入职流程自动化、政策问答、80% 问题自助解决 | 知识库 + 智能体 |
| **数据分析** | 用自然语言查数据库，不会 SQL 的业务人员也能分析 | NL2SQL + 数据库 |
| **客服 / 工单** | 自动分类、自动派单、进度跟踪，与 CRM 打通 | 工作流 + Webhook |
| **教育** | 学情分析、智能组卷、作文辅导、薄弱点诊断 | 知识库 + 工作流 |
| **制造 / 质检** | 工艺参数查询、质检标准比对、AI 定位到原文段落 | 知识图谱 + RAG |
| **政务 / 平台** | 多模型统一接入，后台自由切换，下游机构只对接一个接口 | 多模型网关 |
