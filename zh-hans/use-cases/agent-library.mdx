智能体模板用于沉淀经过验证的场景方案。团队可以把常见任务封装成标准智能体，降低重复配置成本，并让业务人员直接使用。

## 法务 & 合同

| 模板 | 说明 |
| --- | --- |
| 合同审核助手 | 三分钟完成合同初筛、条款提取与风险标注，输出结构化审核报告，附原文引用 |
| 法律文书生成 | 输入案件信息自动生成格式标准、逻辑严谨的法律文书 |

## 办公场景

| 模板 | 说明 |
| --- | --- |
| 发票登记与查验 | 自动录入发票信息、真伪查验、合规性检测，防止重复报销和虚假发票 |
| 会议纪要整理 | 上传录音或文字记录，自动提取议题、决议、待办事项，生成标准化纪要 |
| 周报月报生成 | 汇总项目进度、任务完成情况，自动生成结构清晰的周报或月报初稿 |
| 制度规范问答 | 基于企业制度文档构建知识库，员工随时查询考勤、报销、审批等规范 |

## 教育

| 模板 | 说明 |
| --- | --- |
| 一键学情分析 | 上传成绩单自动生成全面学习画像，快速定位薄弱环节与提升方向 |
| 智能组卷 | 基于知识图谱与难度系数，自动生成结构合理、难度适中的考试试卷 |

## 运营 & 创作

| 模板 | 说明 |
| --- | --- |
| 推文创作助手 | 快速生成公众号文章初稿，支持品牌风格定制和 SEO 优化 |
| 赛后复盘 AI 助教 | 自动解析比赛数据，生成战术复盘报告，标注关键时刻与改进建议 |
