# 智能体库

智能体库用于沉淀可复用的智能体模板。团队可以把常见任务封装成标准智能体，让更多成员直接使用，而不是每次从零配置。

## 常见智能体类型

- 知识库问答助手
- 客服回复助手
- 文档摘要助手
- 数据分析助手
- 代码和研发助手
- 流程审批助手

## 模板应包含什么

一个可复用模板建议包含：

- 适用场景
- 角色说明
- 输入要求
- 可访问知识库
- 可调用工具
- 输出格式
- 风险提示

## 治理建议

智能体数量变多后，应建立审核、发布、下线和版本管理机制，避免团队成员使用过期或未经验证的模板。
