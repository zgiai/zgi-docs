# ZGI 平台介绍

ZGI 是一个强大的企业级 AI 开发平台，专注于可视化 Agent 工作流设计、先进的 RAG 系统和多 Agent 编排。

## 核心特性

### Agent 编排平台
构建复杂 AI 工作流的可视化简易性。企业级 Agent 编排系统，让您通过直观的可视化界面设计、部署和管理复杂的多 Agent 工作流。

### 知识检索系统
将企业数据转化为可操作的智能。高级 RAG（检索增强生成）引擎，将您组织的文档、数据库和知识库转换为智能、可查询的系统。

### 多模型网关
通过单一 API 访问 1000+ AI 模型。通用 AI 模型路由器，通过统一接口无缝访问来自多个提供商的 1000+ 模型。

### 结构化数据库管理
基于 PostgreSQL 的企业级 SQL 数据库，具有 AI 辅助的 schema 设计、智能数据导入以及与 AI 工作流的无缝集成。

### 可扩展插件架构
连接任何服务、API 或数据源。基于 MCP 和 Function Calling 等行业标准构建的综合插件生态系统。

### 企业部署选项
灵活、安全、可扩展的基础设施。多种部署选项，满足企业安全和合规要求。

## 快速开始

```bash
# 安装 ZGI CLI
npm install -g @zgi/cli

# 创建新项目
zgi init my-project

# 启动开发服务器
cd my-project
zgi dev
```
