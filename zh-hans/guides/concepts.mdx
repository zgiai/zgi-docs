## 组织与协作

ZGI 的协作单元从大到小依次为：组织 → 部门 → 工作区 → 成员。这套结构与企业实际的组织架构对齐。

| 概念 | 说明 |
| --- | --- |
| **组织（Organization）** | 企业级管理边界，包含成员、部门、角色、工作区和订阅权益 |
| **部门（Department）** | 按企业组织架构维护成员，可用于批量加入工作区和成员归属管理 |
| **工作区（Workspace）** | AI 资源协作空间，包含成员、智能体、知识库、数据库、文件和应用 |
| **成员（Member）** | 具体使用 ZGI 的人，可以归属于多个工作区，拥有不同角色 |
| **角色（Role）** | 组织角色（owner / admin / normal）+ 工作区角色（自定义）两层权限体系 |

## 智能体相关

| 概念 | 说明 |
| --- | --- |
| **智能体（Agent）** | 基于 ZGI 构建的 AI 应用，分为对话型和工作流型两种类型 |
| **工作流（Workflow）** | 智能体内部的多步骤业务流程，由节点连线构成 |
| **节点（Node）** | 工作流中的基本执行单元，如开始节点、LLM 节点、知识检索节点等 |
| **变量（Variable）** | 节点间传递数据的载体，分为环境变量、会话变量和节点变量 |
| **API Key** | 智能体或开发者调用 ZGI 的凭证，可设置额度、过期时间、模型范围和 IP 白名单 |

## 知识库相关

| 概念 | 说明 |
| --- | --- |
| **知识库（Knowledge Base）** | 面向某一业务领域建立的知识集合，按工作区管理，可通过文件夹分类 |
| **文档（Document）** | 导入知识库的原始资料，系统记录语言、字数、命中次数、分段数量、索引状态等 |
| **分段（Segment）** | 文档清洗、切分后的最小召回单元，可启用、停用、编辑、删除、批量导入 |
| **子分段（Child Chunk）** | 用于更细粒度的内容维护，适合长段落、层级资料和精细召回场景 |
| **RAG** | 检索增强生成，先从知识库检索相关内容，再让模型基于内容生成回答 |
| **命中测试** | 在发布应用前用真实问题验证召回结果，包含单次测试、批量测试和测试报告 |

## 模型相关

| 概念 | 说明 |
| --- | --- |
| **供应商（Provider）** | OpenAI、Anthropic、Google、国内模型服务商以及企业自定义供应商 |
| **模型（Model）** | 记录模型名称、能力类型、上下文窗口、输入/输出价格、能力标签和启用状态 |
| **通道（Channel）** | 承载真实调用凭证、Base URL、模型列表、优先级、权重、余额和连通性状态 |
| **默认模型（Default Model）** | 按对话、向量、重排、视觉、生图等用途设置默认模型，降低应用配置成本 |
| **计费（Billing）** | 调用前额度预扣，调用完成后按实际 Token、模型价格和通道信息结算 |

## 费用治理相关

| 概念 | 说明 |
| --- | --- |
| **订阅套餐** | 免费体验版、团队版、专业版、企业版，包含席位、存储、AI 点数、功能权益 |
| **钱包余额** | 账户可用余额，可用于充值、订阅购买或组合支付 |
| **AI 点数** | 区分官方 AI 点数和私有通道资金，便于同时管理平台模型与企业自有通道 |
| **工作区额度** | 按工作区配置 unlimited 或 custom 额度，记录已用、剩余、上限 |
| **API Key 额度** | 每个 API Key 可设置无限或自定义额度，按 Key 维度追踪消耗 |
| **账单流水** | 按时间、类型、关键词分页查询交易记录，支持导出 Excel |
