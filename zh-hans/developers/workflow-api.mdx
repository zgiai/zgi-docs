# 工作流 API

工作流 API 用于让外部系统触发 ZGI 中的自动化流程。它适合接入业务系统、内部平台、定时任务或第三方服务。

## 常见操作

- 创建或更新工作流定义
- 触发一次工作流运行
- 查询运行状态
- 获取运行结果
- 读取步骤日志和错误信息
- 取消正在运行的任务

## 典型调用流程

1. 外部系统提交输入参数。
2. ZGI 创建一次工作流运行记录。
3. 工作流按节点顺序执行。
4. 外部系统轮询状态或接收回调。
5. 调用方读取最终输出和运行日志。

## 鉴权建议

生产环境中应为不同业务系统分配独立 API Key，并限制访问范围、来源 IP 和过期时间。高风险工作流建议增加人工确认或审批节点。
