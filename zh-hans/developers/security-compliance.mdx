安全与合规是企业使用 ZGI 的基础要求。ZGI 的安全体系覆盖数据传输、存储加密、租户隔离、访问控制、审计日志和私有化部署。

## 数据安全

- **传输加密**：生产环境中的 API 请求和控制台访问应通过 TLS 加密。
- **存储加密**：知识库数据、向量数据和敏感配置应启用加密存储。
- **数据隔离**：多租户和多工作区场景下，数据访问范围应严格隔离。
- **私有化不出域**：私有化部署下，文档解析、OCR、检索和模型调用链路可以运行在企业内网。

## 访问控制

- **RBAC 权限管理**：按角色控制功能和资源访问，遵循最小权限原则。
- **API Key 管理**：支持按 Key 限制权限范围、来源 IP 和有效期。
- **操作审计日志**：记录管理员操作、数据访问、模型调用和关键配置变更。
- **SSO 强制登录**：可对接企业身份系统，统一账号、组织和登录策略。

## 合规认证状态

官网文档中心目前标注的合规状态如下。正式对外承诺仍应以合同、安全白皮书、审计报告或证书原件为准。

| 认证 | 状态 | 说明 |
| --- | --- | --- |
| SOC 2 Type II | 已认证 | 安全性、可用性、保密性审计 |
| GDPR | 已认证 | 欧盟数据保护合规 |
| HIPAA | 准备中 | 医疗数据合规，预计 2026 Q2 |
| 等保三级 | 准备中 | 国内网络安全等级保护，预计 2026 Q2 |

## 发布前检查

在销售材料、官网或招投标文档中使用合规声明前，应确认：

- 认证主体是否覆盖当前产品和部署方式。
- 证书或报告是否仍在有效期内。
- 数据处理协议、隐私政策和安全白皮书是否一致。
- 私有化部署、云端 SaaS 和混合架构的责任边界是否分别说明。
