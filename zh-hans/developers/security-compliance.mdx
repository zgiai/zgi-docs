# 安全与合规

安全与合规是企业使用 ZGI 时必须重点关注的部分。ZGI 的目标是在数据传输、数据存储、权限控制、审计追踪和私有化部署方面提供可验证、可管理的安全基础。

## 数据安全

- **传输加密**：生产环境应通过 TLS 加密 API 请求和管理后台访问。
- **存储加密**：知识库原文、向量数据和敏感配置应根据部署要求启用存储加密。
- **数据隔离**：多租户场景下，应按工作区或租户隔离数据访问范围。
- **私有化不出域**：私有化部署时，文档解析、OCR、检索和模型调用链路应优先在企业内网完成。

## 访问控制

- **角色权限管理**：按角色控制用户可以访问的功能和资源，遵循最小权限原则。
- **API Key 管理**：为不同系统分配独立密钥，并限制权限范围、来源 IP 和有效期。
- **操作审计日志**：记录管理员操作、数据访问、模型调用和关键配置变更。
- **企业单点登录**：对接企业身份系统后，可统一管理账号、组织和登录策略。

## 合规状态

以下状态用于规划和跟踪，不应替代正式审计报告或认证证书。

| 项目 | 状态 | 说明 |
| --- | --- | --- |
| SOC 2 Type II | 待确认 | 需以第三方审计报告为准 |
| GDPR | 待确认 | 需确认数据处理协议、数据驻留和用户权利处理流程 |
| HIPAA | 规划中 | 适用于医疗数据场景，需完成专项评估 |
| 等保三级 | 规划中 | 适用于国内政企场景，需结合部署环境测评 |

## 发布前检查

如果对外宣称“已认证”或“已合规”，应先确认以下材料：

- 认证证书或审计报告是否存在
- 认证主体是否覆盖当前产品和部署方式
- 认证有效期是否仍然有效
- 文档描述是否与合同、隐私政策和安全白皮书一致
