# Agent API

## 构造函数

```typescript
new Agent(config: AgentConfig)
```

### AgentConfig

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `name` | string | ✅ | Agent 名称 |
| `model` | string | ✅ | 使用的 LLM 模型 |
| `systemPrompt` | string | ❌ | 系统提示词 |
| `temperature` | number | ❌ | 温度参数 (0-1) |
| `maxTokens` | number | ❌ | 最大 token 数 |
| `tools` | Tool[] | ❌ | 可用工具列表 |

## 方法

### execute()

执行任务。

```typescript
await agent.execute({
  task: string,
  context?: Record<string, any>
}): Promise<AgentResult>
```

### registerTool()

注册工具。

```typescript
agent.registerTool(tool: Tool): void
```

### on()

监听事件。

```typescript
agent.on(event: string, handler: Function): void
```

## 事件

- `start` - Agent 开始执行
- `complete` - Agent 完成执行
- `error` - 发生错误
- `tool_call` - 调用工具
