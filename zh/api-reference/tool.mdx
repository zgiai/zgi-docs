# Tool API

## 构造函数

```typescript
new Tool(config: ToolConfig)
```

### ToolConfig

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `name` | string | ✅ | 工具名称 |
| `description` | string | ✅ | 工具描述 |
| `parameters` | object | ✅ | 参数定义 |
| `handler` | Function | ✅ | 执行函数 |

## 示例

```typescript
const tool = new Tool({
  name: 'calculator',
  description: '执行数学计算',
  parameters: {
    expression: { type: 'string', required: true }
  },
  handler: async (params) => {
    return eval(params.expression);
  }
});
```
