# Memory API

## 方法

### add()

添加记忆。

```typescript
memory.add({
  role: 'user' | 'assistant',
  content: string
}): void
```

### search()

搜索相关记忆。

```typescript
await memory.search(query: string): Promise<Memory[]>
```

### clear()

清空记忆。

```typescript
memory.clear(): void
```
