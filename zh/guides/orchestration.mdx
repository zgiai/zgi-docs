# Agent 编排

Agent 编排允许你组合多个 Agent 来完成复杂任务。

## 基础编排

```typescript
import { Workflow } from '@zgi/orchestration';

const workflow = new Workflow()
  .addAgent('researcher', {
    role: 'research',
    tools: ['web_search', 'document_reader']
  })
  .addAgent('writer', {
    role: 'content',
    tools: ['markdown_generator']
  })
  .connect('researcher', 'writer');

const result = await workflow.execute({
  task: '研究 AI 趋势并写一篇文章'
});
```

## 并行执行

```typescript
workflow
  .addAgent('agent1', config1)
  .addAgent('agent2', config2)
  .parallel(['agent1', 'agent2']);
```

## 条件分支

```typescript
workflow
  .addAgent('classifier', classifierConfig)
  .branch({
    condition: (result) => result.category,
    branches: {
      'technical': 'techAgent',
      'business': 'bizAgent'
    }
  });
```
