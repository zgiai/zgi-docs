## Scenario Overview

| Scenario | Capabilities | Core Features |
|---|---|---|
| **Legal / Contracts** | Clause extraction, risk annotation, version comparison — every conclusion cites the source | Knowledge Graph + RAG |
| **Office Collaboration** | Meeting minutes, weekly reports, policy Q&A, approval automation | Knowledge Base + Workflow |
| **HR / Records** | Onboarding automation, policy Q&A, 80% of questions self-resolved | Knowledge Base + Agent |
| **Data Analytics** | Query databases in natural language — no SQL required | NL2SQL + Database |
| **Education** | Learning analytics, smart exam generation, essay tutoring | Knowledge Base + Workflow |
| **Manufacturing / QC** | Process parameter lookup, QC standard comparison, source paragraph citation | Knowledge Graph + RAG |
| **Government / Platform** | Unified multi-model access, backend hot-swap, one interface for downstream agencies | Multi-Model Gateway |
