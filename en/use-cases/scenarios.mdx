## Case Studies

### CAICT — National LLM Public Service Platform

**Challenge:** Unify dozens of LLM providers nationwide. Regional agencies each maintaining separate integrations was unsustainable.

**Solution:** ZGI's unified model gateway as the core access layer. All providers connect to ZGI once; all downstream agencies call a single interface. New models onboard by changing gateway config — zero application code changes.

**Result:** One platform managing all national LLMs. Now serving as CAICT's foundational infrastructure for AI adoption across government and industry parks.

### CAICT — OPC Intelligent Service Platform

**Challenge:** Build an AI productivity tool for grassroots government workers who have no technical background — it must work out of the box.

**Solution:** Based on ZGI's no-code workflow orchestration, CAICT built the OPC platform with preset scenarios (video generation, PPT creation, audio synthesis). Users drag and drop — no coding, no API configuration.

**Result:** Extremely short time from zero to launch, entirely on ZGI. Already signed multiple government district and community clients. ZGI serves as the "AI capability base" — one deployment, replicated to many downstream customers.

### Shandong Lanhai Group — Smart Property Customer Service

**Challenge:** Property customer service overwhelmed — residents call to report issues, staff manually log and dispatch. Peak hours cause backlogs; nights have zero coverage.

**Solution:** ZGI-powered property agent: residents describe issues via WeChat → agent auto-classifies (repair / complaint / inquiry) → auto-creates work orders → auto-dispatches. Knowledge graph enhanced retrieval accurately maps "issue type → department → SLA".

**Result:**
- **40% reduction** in manual intervention
- **24/7** automated response
- **Real-time** work order creation and dispatch
