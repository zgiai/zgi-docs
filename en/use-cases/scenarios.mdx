## Scene Overview

| Scenario | What can be done | Core competencies |
| --- | --- | --- |
| **Contract/Legal** | Extraction of contract terms, risk annotation, version comparison, and original text source for each conclusion | Knowledge Graph + RAG |
| **Office Collaboration** | Meeting minutes compilation, weekly report generation, system standard Q&A, approval process automation | Knowledge base + workflow |
| **HR/File** | Automation of onboarding process, policy Q&A, 80% self-service solution | Knowledge base + agent |
| **Data Analysis** | Use natural language to query the database, and business personnel who do not know SQL can also analyze it | NL2SQL + database |
| **Customer Service/Work Order** | Automatic classification, automatic order dispatch, progress tracking, and integration with CRM | Workflow + Webhook |
| **Education** | Academic situation analysis, intelligent examination preparation, composition guidance, weak point diagnosis | Knowledge base + workflow |
| **Manufacturing/Quality Inspection** | Process parameter query, quality inspection standard comparison, AI positioning to the original text paragraph | Knowledge Map + RAG |
| **Government Affairs/Platform** | Unified access to multiple models, free backend switching, downstream institutions only connect to one interface | Multi-model gateway |
