# Agent Templates

All templates below are reusable starting points and can be imported with one click.

## Legal & Contracts

| Agent | Description |
|---|---|
| **Contract Review Assistant** | Complete initial screening, clause extraction, and risk annotation in 3 minutes. Outputs structured review report with source citations and legal references. |
| **Legal Document Generator** | Input case details to auto-generate properly formatted, logically rigorous legal documents. |

## Office & Productivity

| Agent | Description |
|---|---|
| **Invoice Registration & Verification** | Auto-capture invoice info, verify authenticity, compliance check — prevents duplicate reimbursement and fake invoices. |
| **Meeting Minutes Organizer** | Upload recordings or text notes. Auto-extract topics, decisions, and action items into standardized minutes. |
| **Weekly/Monthly Report Generator** | Aggregate project progress and task completion into well-structured draft reports. |
| **Policy & Regulation Q&A** | Build knowledge base from company policy documents. Employees can query attendance, reimbursement, approval rules anytime. |

## Operations & Content

## Creating Custom Agents

Beyond templates, ZGI supports building agents from scratch:

1. **Choose agent type** — Conversational or Workflow
2. **Configure base settings** — Name, icon, description, permissions
3. **Build workflow** — Drag nodes on the visual canvas
4. **Connect knowledge & data** — Link knowledge bases and databases
5. **Test & debug** — Use the built-in SSE debug panel
6. **Publish** — One-click deploy as Web App or API endpoint

Templates can also be exported as YAML files for sharing across teams and organizations.
