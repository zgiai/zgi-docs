## Deployment Options

| Method | Best For | Data Location | Time to Launch |
|---|---|---|---|
| **Cloud SaaS** | Quick validation, small teams | ZGI cloud (encrypted) | Instant |
| **Docker Compose** | Dev environment, small production | Enterprise intranet | 1 hour |
| **Kubernetes** | Production high availability | Enterprise intranet | 30 minutes |
| **Enterprise On-Premise** | Finance, government, healthcare | Fully self-controlled | 3 business days |

## Open Source — Quick Start

ZGI's core framework is fully open source. Clone and run:

### macOS / Linux (Recommended)

```bash
git clone https://github.com/zgiai/zgi.git
cd zgi
make dev-docker
```

`make dev-docker` auto-completes on first run: initialize submodules → copy env templates → generate compose → start stack.

### China Mainland Mirror

```bash
./dev/start-docker --china
```

### Source Code Development

Run `api/` and `web/` from source, with middleware via Docker:

```bash
make setup
make dev-docker
make dev-api
make dev-web
```

### Windows

```powershell
.\dev\start-docker.ps1
# With China mirrors:
.\dev\start-docker.ps1 -china
```

### Environment Variable Management

```bash
# Check env vs template diff
make env-check

# Append missing keys (does not overwrite existing values)
make env-sync
```

## Enterprise Docker Compose

```bash
wget https://releases.zgi.cn/zgi-v2026-enterprise.tar.gz
tar -xzf zgi-v2026-enterprise.tar.gz && cd zgi-enterprise
cp .env.example .env
# Edit .env with License Key, database connection, etc.
docker-compose up -d
docker-compose ps
```

## Kubernetes

```bash
helm repo add zgi https://charts.zgi.cn
helm install zgi zgi/zgi \
  --namespace zgi --create-namespace \
  --set global.storageClass=your-storage-class \
  --values values-production.yaml
```

## Default Service Addresses

| Service | Address | Notes |
|---|---|---|
| Web Frontend | `http://localhost:13000` | Console UI |
| API Backend | `http://localhost:2678` | REST API |
| PostgreSQL | `localhost:15432` | Primary database |
| Redis | `localhost:16379` | Cache & queue |
| Weaviate | `http://localhost:18080` | Vector database |
| Neo4j | `http://localhost:17474` | Knowledge graph |
| Sandbox | `http://localhost:18194` | Code execution |
| Plugin Runner | `http://localhost:15000` | Plugin runner |

> All ports can be customized via `HOST_*_PORT` variables in `.env`.
