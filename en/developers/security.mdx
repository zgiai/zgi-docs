## Security Architecture

- **Transport Encryption** — All API requests encrypted via TLS 1.3
- **Storage Encryption** — Knowledge base data and vectors encrypted with AES-256
- **Data Isolation** — Strict multi-tenant isolation; workspace data invisible to others
- **Key Management** — API keys stored with AES-GCM encryption; frontend shows masked values only
- **Audit Trail** — All admin operations fully logged, tamper-proof
