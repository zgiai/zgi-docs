# Multi-Model Gateway Guide

Learn how to access and manage 1000+ AI models from multiple providers through a unified interface.

## What is Multi-Model Gateway?

The Multi-Model Gateway is a universal AI model router that provides seamless access to 1000+ models from multiple providers including OpenAI, Anthropic, Google, Meta, Mistral, DeepSeek, and more. It features intelligent load balancing, automatic failover, and multi-channel support for optimal performance and reliability.

### Gateway Features

**Core Capabilities:**
- **1000+ Models** - Access to 1000+ models from major providers
- **Unified API** - Single API compatible with OpenAI SDK
- **Intelligent Routing** - Automatic routing to best provider
- **Load Balancing** - Distribute load across providers
- **Automatic Failover** - Failover to alternative providers
- **Cost Optimization** - Optimize costs automatically

**Advanced Features:**
- **Multi-Channel Support** - Support multiple communication channels
- **Real-time Monitoring** - Monitor model availability
- **Rate Limiting** - Per-model rate limiting
- **Quota Management** - Manage usage quotas
- **Usage Analytics** - Track usage and costs
- **Custom Routing** - Define custom routing rules

## Accessing Models

```typescript
import { MultiModelGateway } from '@zgi/core';

const gateway = new MultiModelGateway({
  apiKey: 'your-api-key'
});

// List available models
const models = await gateway.listModels();
console.log(models);

// Get model details
const modelInfo = await gateway.getModel('gpt-4');
console.log(modelInfo.provider);
console.log(modelInfo.pricing);
console.log(modelInfo.capabilities);
```

## Making API Calls

```typescript
// Simple completion
const response = await gateway.createCompletion({
  model: 'gpt-4',
  messages: [
    { role: 'system', content: 'You are a helpful assistant' },
    { role: 'user', content: 'Hello!' }
  ],
  temperature: 0.7,
  maxTokens: 1000
});

console.log(response.choices[0].message.content);

// Streaming
const stream = await gateway.createCompletionStream({
  model: 'gpt-4',
  messages: [{ role: 'user', content: 'Tell me a story' }]
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0].delta.content);
}
```

## Intelligent Routing

```typescript
// Auto-routing based on criteria
const response = await gateway.createCompletion({
  messages: [{ role: 'user', content: 'Hello' }],
  routing: {
    strategy: 'cost-optimized',
    maxLatency: 5000,
    preferredProviders: ['openai', 'anthropic']
  }
});

// Custom routing rules
const customRouter = gateway.createRouter({
  rules: [
    {
      condition: { capability: 'vision' },
      provider: 'gpt-4-vision'
    },
    {
      condition: { costBudget: { max: 0.01 } },
      provider: 'gpt-3.5-turbo'
    }
  ]
});
```
