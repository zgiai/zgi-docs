# Plugin Architecture Guide

Learn how to build and integrate plugins to connect your agents to any service, API, or data source.

## What is a Plugin?

A Plugin is a reusable component that extends ZGI's capabilities by connecting to external services, APIs, and data sources. Built on industry standards like MCP (Model Context Protocol) and Function Calling, plugins provide secure, scalable connectivity to your entire technology stack.

### Plugin Features

**Core Capabilities:**
- **Pre-built Connectors** - 50+ pre-built connectors for popular services
- **Custom Development** - Build custom plugins with SDK
- **OAuth 2.0 Support** - Secure OAuth 2.0 authentication

- **Rate Limiting** - Built-in rate limiting
- **Error Handling** - Comprehensive error handling

**Advanced Features:**

## Building Custom Plugins

```typescript
import { Plugin } from '@zgi/plugin-sdk';

class MyCustomPlugin extends Plugin {
  name = 'my-custom-plugin';
  version = '1.0.0';
  description = 'My custom plugin';

  async initialize(config) {
    this.apiKey = config.apiKey;
    this.baseUrl = config.baseUrl;
  }

  async execute(action, params) {
    switch (action) {
      case 'get_data':
        return this.getData(params);
      case 'create_data':
        return this.createData(params);
      default:
        throw new Error(`Unknown action: ${action}`);
    }
  }

  private async getData(params) {
    const response = await fetch(`${this.baseUrl}/data/${params.id}`, {
      headers: { 'Authorization': `Bearer ${this.apiKey}` }
    });
    return response.json();
  }

  private async createData(params) {
    const response = await fetch(`${this.baseUrl}/data`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${this.apiKey}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(params)
    });
    return response.json();
  }
}

export default MyCustomPlugin;
```
