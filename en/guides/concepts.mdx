## Organization and Collaboration

ZGI's collaboration units from large to small are: organization → department → workspace → member. This structure is aligned with the actual organizational structure of the business.

| Concept | Description |
| --- | --- |
| **Organization** | Enterprise-level management boundaries, including members, departments, roles, workspaces and subscription rights |
| **Department** | Maintain members according to the enterprise organizational structure, which can be used to join workspaces in batches and manage member ownership |
| **Workspace** | AI resource collaboration space, including members, agents, knowledge bases, databases, files and applications |
| **Member** | People who use ZGI can belong to multiple workspaces and have different roles |
| **Role** | Organization role (owner/admin/normal) + workspace role (custom) two-tier permission system |

## Agent related

| Concept | Description |
| --- | --- |
| **Agent** | AI applications built based on ZGI are divided into two types: conversational and workflow types |
| **Workflow** | The multi-step business process within the agent, consisting of node connections |
| **Node** | The basic execution unit in the workflow, such as start node, LLM node, knowledge retrieval node, etc. |
| **Variable** | The carrier for transferring data between nodes, divided into environment variables, session variables and node variables |
| **API Key** | Credentials for agents or developers to call ZGI. The limit, expiration time, model range and IP whitelist can be set |

## Knowledge base related

| Concept | Description |
| --- | --- |
| **Knowledge Base** | A collection of knowledge established for a certain business field, managed by workspace, and can be classified by folders |
| **Document** | Import the original data into the knowledge base, and the system records the language, word count, number of hits, number of segments, index status, etc. |
| **Segment** | The smallest recall unit after document cleaning and segmentation, which can be enabled, disabled, edited, deleted, and imported in batches |
| **Child Chunk** | Used for more fine-grained content maintenance, suitable for long paragraphs, hierarchical information and fine recall scenarios |
| **RAG** | Retrieval enhancement generation, first retrieve relevant content from the knowledge base, and then let the model generate answers based on the content |
| **Hit Test** | Verify recall results with real problems before releasing the application, including single test, batch test and test report |

## Model related

| Concept | Description |
| --- | --- |
| **Provider** | OpenAI, Anthropic, Google, domestic model service providers and enterprise custom suppliers |
| **Model** | Records model name, capability type, context window, input/output price, capability label and enabled status |
| **Channel** | Carrying real calling credentials, Base URL, model list, priority, weight, balance and connectivity status |
| **Default Model** | Set default models according to dialogue, vector, rearrangement, vision, drawing and other purposes to reduce application configuration costs |
| **Billing** | The amount is withheld before the call is made. After the call is completed, the settlement will be based on the actual Token, model price and channel information |

## Expense management related

| Concept | Description |
| --- | --- |
| **Subscription Package** | Free trial version, team version, professional version, enterprise version, including seats, storage, AI points, functional benefits |
| **Wallet Balance** | The available balance in the account, which can be used for top-up, subscription purchase or combined payment |
| **AI Points** | Distinguish official AI points and private channel funds to facilitate simultaneous management of platform models and enterprise-owned channels |
| **Workspace quota** | Configure unlimited or custom quota according to workspace, record used, remaining, upper limit |
| **API Key Quota** | Each API Key can set unlimited or customized quota, and track consumption by Key dimension |
| **Bill flow** | Query transaction records by time, type, and keywords, and support exporting to Excel |
