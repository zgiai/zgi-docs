# Structured Database Guide

Learn how to build and manage structured databases with AI-powered intelligence.

## What is Structured Database Management?

Structured Database Management is a comprehensive platform for managing relational data with AI-assisted schema design, intelligent data import, and seamless integration with AI workflows. Built on PostgreSQL, it provides enterprise-grade reliability with modern AI capabilities.

### Database Features

**Core Capabilities:**
- **AI-Powered Schema Design** - Automatically infer schemas from data
- **Visual Table Designer** - Design tables with drag-and-drop interface
- **Intelligent Data Import** - Automatically convert and validate data
- **Multi-tenant Isolation** - Isolate data per tenant with granular permissions
- **Native SQL Support** - Execute raw SQL queries safely
- **Dual-Mode Architecture** - Use PostgreSQL directly or HTTP API

**Advanced Features:**
- **Automatic System Fields** - Auto-generated id, uuid, timestamps
- **Type Conversion** - Intelligent type detection and conversion
- **Data Validation** - Automatic data validation and constraints
- **Parameterized Queries** - Prevent SQL injection attacks
- **Connection Pooling** - Efficient connection management
- **Query Optimization** - Automatic query optimization

## Creating Tables

```typescript
// Using visual designer
const table = await db.createTable({
  name: 'users',
  columns: [
    {
      name: 'id',
      type: 'uuid',
      primaryKey: true,
      autoGenerate: true
    },
    {
      name: 'email',
      type: 'string',
      unique: true,
      required: true
    },
    {
      name: 'name',
      type: 'string',
      required: true
    },
    {
      name: 'age',
      type: 'number',
      minimum: 0,
      maximum: 150
    },
    {
      name: 'created_at',
      type: 'timestamp',
      autoGenerate: true
    },
    {
      name: 'updated_at',
      type: 'timestamp',
      autoGenerate: true,
      autoUpdate: true
    }
  ]
});

// Using SQL
const result = await db.execute(`
  CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    name VARCHAR(255) NOT NULL,
    age INTEGER CHECK (age >= 0 AND age <= 150),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  )
`);
```

**Column Constraints:**

**System Fields:**

## Data Operations

### Insert Data

```typescript
// Single insert
const user = await db.table('users').insert({
  email: 'user@example.com',
  name: 'John Doe',
  age: 30
});

// Batch insert
const users = await db.table('users').insertMany([
  { email: 'user1@example.com', name: 'User 1', age: 25 },
  { email: 'user2@example.com', name: 'User 2', age: 30 },
  { email: 'user3@example.com', name: 'User 3', age: 35 }
]);
```

**Insert Features:**
- **Single Insert** - Insert single record
- **Batch Insert** - Insert multiple records
- **Upsert** - Insert or update
- **Default Values** - Use default values
- **Auto-generation** - Auto-generate fields
- **Validation** - Validate data before insert
- **Transactions** - Transactional inserts
- **Returning** - Return inserted records

### Query Data

```typescript
// Simple query
const users = await db.table('users').find();

// With filters
const adults = await db.table('users')
  .where('age', '>=', 18)
  .where('status', '=', 'active')
  .select(['id', 'name', 'email'])
  .orderBy('created_at', 'DESC')
  .limit(10)
  .offset(0);

// Using SQL
const result = await db.execute(
  'SELECT * FROM users WHERE age >= $1 AND status = $2',
  [18, 'active']
);
```

**Query Features:**
- **Filtering** - Filter by conditions
- **Selection** - Select specific columns
- **Sorting** - Sort by columns
- **Pagination** - Limit and offset
- **Aggregation** - Count, sum, avg, min, max
- **Grouping** - Group by columns
- **Joining** - Join multiple tables
- **Subqueries** - Use subqueries

### Update Data

- **Conditional Update** - Update based on conditions
- **Partial Update** - Update specific fields

## Advanced Features

### Relationships

```typescript
// Define relationships
const usersTable = await db.createTable({
  name: 'users',
  columns: [/* ... */]
});

const postsTable = await db.createTable({
  name: 'posts',
  columns: [
    { name: 'id', type: 'uuid', primaryKey: true },
    { name: 'user_id', type: 'uuid', foreignKey: 'users.id' },
    { name: 'title', type: 'string' },
    { name: 'content', type: 'text' }
  ]
});

// Query with relationships
const userWithPosts = await db.table('users')
  .where('id', '=', userId)
  .include('posts')
  .first();
```

**Relationship Features:**
- **One-to-Many** - One user has many posts
- **Many-to-One** - Many posts belong to one user
- **Many-to-Many** - Many users have many roles
- **Eager Loading** - Load related data efficiently
- **Lazy Loading** - Load related data on demand
- **Cascade Operations** - Cascade deletes and updates
- **Relationship Queries** - Query through relationships
- **Polymorphic Relationships** - Support polymorphic relations

### Transactions

```typescript
const transaction = await db.transaction();

try {
  await transaction.table('users').update({ balance: 100 });
  await transaction.table('logs').insert({ action: 'update' });
  await transaction.commit();
} catch (error) {
  await transaction.rollback();
}
```

**Transaction Features:**
- **ACID Compliance** - Ensure ACID properties
- **Rollback** - Rollback on error
- **Savepoints** - Create savepoints
- **Isolation Levels** - Configure isolation levels
- **Deadlock Handling** - Handle deadlocks
- **Timeout** - Set transaction timeouts
- **Nested Transactions** - Support nested transactions
- **Monitoring** - Monitor transactions
