# Agents API

Complete reference for agent management endpoints.

## List Agents

### Endpoint
```
GET /console/api/v1/agents
```

### Description
List all agents.

### Query Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| page | integer | Page number |
| limit | integer | Items per page |

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": [
    {
      "id": "agent_123",
      "name": "My Agent",
      "type": "chat",
      "status": "active"
    }
  ]
}
```

### Try it out

<APITester
  method="GET"
  endpoint="/console/api/v1/agents"
  description="List all agents with pagination"
  queryParams={{
    page: {
      type: 'integer',
      description: 'Page number (default: 1)'
    },
    limit: {
      type: 'integer',
      description: 'Items per page (default: 10)'
    }
  }}
/>

### Examples

#### cURL
```bash
curl -X GET "http://localhost:8080/console/api/v1/agents?page=1&limit=10" \
  -H "Authorization: Bearer $TOKEN"
```

## Create Agent

### Endpoint
```
POST /console/api/v1/agents
```

### Description
Create a new agent.

### Request Body
```json
{
  "name": "My Agent",
  "type": "chat",
  "description": "A helpful agent"
}
```

### Response (201)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "id": "agent_456",
    "name": "My Agent",
    "type": "chat",
    "status": "active"
  }
}
```

### Try it out

<APITester
  method="POST"
  endpoint="/console/api/v1/agents"
  description="Create a new AI agent"
  body={`{
  "name": "My Agent",
  "type": "chat",
  "description": "A helpful agent"
}`}
/>

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/agents \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My Agent",
    "type": "chat"
  }'
```

### Response (200)

  "code": "0",
  "message": "success",
  "data": {

    "name": "Updated Agent"

## Delete Agent

### Endpoint
```
DELETE /console/api/v1/agents/:agent_id
```

### Description
Delete an agent.

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "message": "Agent deleted"
  }
}
```

### Examples

#### cURL
```bash
curl -X DELETE http://localhost:8080/console/api/v1/agents/agent_123 \
  -H "Authorization: Bearer $TOKEN"
```
