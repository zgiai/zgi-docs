# API Keys API

Complete reference for API key management endpoints.

## List API Keys

### Endpoint
```
GET /console/api/v1/agents/:agent_id/api-keys
```

### Description
List all API keys for an agent.

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": [
    {
      "id": "key_123",
      "name": "My API Key",
      "status": "active",
      "daily_quota": 1000,
      "daily_usage": 250
    }
  ]
}
```

### Examples

#### cURL
```bash
curl -X GET http://localhost:8080/console/api/v1/agents/agent_123/api-keys \
  -H "Authorization: Bearer $TOKEN"
```

## Create API Key

### Endpoint
```
POST /console/api/v1/agents/:agent_id/api-keys
```

### Description
Create a new API key.

### Request Body
```json
{
  "name": "My API Key",
  "daily_quota": 1000,
  "monthly_quota": 30000
}
```

### Response (201)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "id": "key_456",
    "key": "zgi_sk_abc123...",
    "name": "My API Key",
    "status": "active"
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/agents/agent_123/api-keys \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My API Key",
    "daily_quota": 1000
  }'
```
