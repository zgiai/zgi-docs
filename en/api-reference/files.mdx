# Files API

Complete reference for file management endpoints.

## List Files

### Endpoint
```
GET /console/api/v1/files
```

### Description
List all files.

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": [
    {
      "id": "file_123",
      "name": "document.pdf",
      "size": 102400,
      "mime_type": "application/pdf"
    }
  ]
}
```

### Examples

#### cURL
```bash
curl -X GET http://localhost:8080/console/api/v1/files \
  -H "Authorization: Bearer $TOKEN"
```

---

## Upload File

### Endpoint
```
POST /console/api/v1/files/upload
```

### Description
Upload a file.

### Request
Multipart form data

### Response (201)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "id": "file_456",
    "name": "document.pdf",
    "size": 102400
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/files/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@document.pdf"
```

## Download File

### Endpoint
```
GET /console/api/v1/files/:file_id/download
```

### Description
Download a file.

### Response
File binary content

### Examples

#### cURL
```bash
curl -X GET http://localhost:8080/console/api/v1/files/file_123/download \
  -H "Authorization: Bearer $TOKEN" \
  -o document.pdf
```
