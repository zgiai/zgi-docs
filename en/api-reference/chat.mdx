# Chat API

Complete reference for chat management endpoints.

## List Conversations

### Endpoint
```
GET /console/api/v1/conversations
```

### Description
List all conversations.

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": [
    {
      "id": "conv_123",
      "title": "Conversation",
      "message_count": 5
    }
  ]
}
```

### Examples

#### cURL
```bash
curl -X GET http://localhost:8080/console/api/v1/conversations \
  -H "Authorization: Bearer $TOKEN"
```

---

## Create Conversation

### Endpoint
```
POST /console/api/v1/conversations
```

### Description
Create a new conversation.

### Request Body
```json
{
  "agent_id": "agent_123",
  "title": "New Conversation"
}
```

### Response (201)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "id": "conv_456",
    "title": "New Conversation"
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/conversations \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "agent_123",
    "title": "New Conversation"
  }'
```

curl -X GET http://localhost:8080/console/api/v1/conversations/conv_123/messages \
