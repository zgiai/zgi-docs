# Workspaces API

Complete reference for workspace management endpoints.

## List Workspaces

### Endpoint
```
GET /console/api/v1/workspaces
```

### Description
List all workspaces.

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": [
    {
      "id": "workspace_123",
      "name": "My Workspace",
      "member_count": 5
    }
  ]
}
```

### Examples

#### cURL
```bash
curl -X GET http://localhost:8080/console/api/v1/workspaces \
  -H "Authorization: Bearer $TOKEN"
```

---

## Create Workspace

### Endpoint
```
POST /console/api/v1/workspaces
```

### Description
Create a new workspace.

### Request Body
```json
{
  "name": "New Workspace",
  "description": "Description"
}
```

### Response (201)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "id": "workspace_456",
    "name": "New Workspace"
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/workspaces \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "New Workspace"
  }'
```
