# Workflows API

Complete reference for workflow management endpoints.

## Get Draft Workflow

### Endpoint
```
GET /console/api/v1/agents/:agent_id/workflows/draft
```

### Description
Get draft workflow for an agent.

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "id": "workflow_123",
    "type": "chat",
    "graph": {"nodes": [], "edges": []}
  }
}
```

### Examples

#### cURL
```bash
curl -X GET http://localhost:8080/console/api/v1/agents/agent_123/workflows/draft \
  -H "Authorization: Bearer $TOKEN"
```

## Sync Draft Workflow

### Endpoint
```
POST /console/api/v1/agents/:agent_id/workflows/draft
```

### Description
Create or update draft workflow.

### Request Body
```json
{
  "type": "chat",
  "graph": {
    "nodes": [],
    "edges": []
  }
}
```

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "result": "success",
    "hash": "abc123"
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/agents/agent_123/workflows/draft \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "chat",
    "graph": {"nodes": [], "edges": []}
  }'
```

## Run Draft Workflow

### Endpoint
```
POST /console/api/v1/agents/:agent_id/workflows/draft/run
```

### Description
Execute draft workflow.

### Request Body
```json
{
  "variables": {
    "input": "test"
  }
}
```

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "run_id": "run_123",
    "status": "completed",
    "output": "result"
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/agents/agent_123/workflows/draft/run \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "variables": {"input": "test"}
  }'
```

## Publish Workflow

### Endpoint
```
POST /console/api/v1/agents/:agent_id/workflows/publish
```

### Description
Publish workflow to production.

### Request Body
```json
{
  "version": "1.0.0",
  "description": "Initial release"
}
```

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "workflow_id": "workflow_xyz",
    "version": "1.0.0",
    "status": "published"
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/agents/agent_123/workflows/publish \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "version": "1.0.0"
  }'
```
