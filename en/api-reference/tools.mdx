# Tools API

Complete reference for tool management endpoints.

## List Tools

### Endpoint
```
GET /console/api/v1/tools
```

### Description
List all tools.

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": [
    {
      "id": "tool_123",
      "name": "Web Search",
      "category": "search",
      "status": "active"
    }
  ]
}
```

### Examples

#### cURL
```bash
curl -X GET http://localhost:8080/console/api/v1/tools \
  -H "Authorization: Bearer $TOKEN"
```

---

## Create Tool

### Endpoint
```
POST /console/api/v1/tools
```

### Description
Create a new tool.

### Request Body
```json
{
  "name": "Web Search",
  "category": "search",
  "endpoint": "https://api.example.com/search"
}
```

### Response (201)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "id": "tool_456",
    "name": "Web Search",
    "status": "active"
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/tools \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Web Search",
    "category": "search"
  }'
```

## Test Tool

### Endpoint
```
POST /console/api/v1/tools/:tool_id/test
```

### Description
Test a tool.

### Request Body
```json
{
  "parameters": {
    "query": "test"
  }
}
```

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "status": "success",
    "response": {}
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/console/api/v1/tools/tool_123/test \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "parameters": {"query": "test"}
  }'
```
