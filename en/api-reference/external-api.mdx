# External API

Complete reference for external API endpoints.

## Health Check

### Endpoint
```
GET /api/health
```

### Description
Check API health status.

### Response (200)
```json
{
  "status": "ok",
  "service": "zgi-external-api",
  "version": "1.0"
}
```

### Examples

#### cURL
```bash
curl -X GET http://localhost:8080/api/health
```

## Run Workflow

### Endpoint
```
POST /api/v1/workflows/run
```

### Description
Execute workflow via external API.

### Authentication
Required: API Key

### Request Body
```json
{
  "variables": {
    "input": "test"
  }
}
```

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "run_id": "run_123",
    "status": "completed",
    "output": "result"
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/api/v1/workflows/run \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "variables": {"input": "test"}
  }'
```

## Chat Completions

### Endpoint
```
POST /api/v1/chat/completions
```

### Description
OpenAI-compatible chat completions.

### Authentication
Required: API Key

### Request Body
```json
{
  "model": "gpt-4",
  "messages": [
    {"role": "user", "content": "Hello"}
  ]
}
```

### Response (200)
```json
{
  "id": "chatcmpl-123",
  "object": "chat.completion",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "Hi there!"
      }
    }
  ]
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/api/v1/chat/completions \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

## Upload File

### Endpoint
```
POST /api/v1/files/upload
```

### Description
Upload file via external API.

### Authentication
Required: API Key

### Request
Multipart form data

### Response (200)
```json
{
  "code": "0",
  "message": "success",
  "data": {
    "file_id": "file_123",
    "name": "document.pdf"
  }
}
```

### Examples

#### cURL
```bash
curl -X POST http://localhost:8080/api/v1/files/upload \
  -H "Authorization: Bearer $API_KEY" \
  -F "file=@document.pdf"
```
