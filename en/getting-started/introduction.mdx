# What Is ZGI

ZGI is an enterprise-grade **AI operations and management platform** that connects data, knowledge, models, and workflows through a unified agent orchestration framework — turning scattered AI capabilities into usable, controllable, and accumulable assets.

<Info>
**ZGI is not an AI tool — it's the infrastructure layer that makes AI tools actually work.**

Most enterprises don't lack better models. They lack the layer that unifies, governs, and retains all their AI capabilities.
</Info>

## What Problems Does It Solve

Enterprise AI adoption typically gets stuck on three problems:

### 1. AI Asset Loss

Carefully tuned prompts live on employees' personal devices — when they leave, the knowledge disappears. ZGI ensures all AI assets belong to the organization, with version tracking and automatic handoff on offboarding.

### 2. Untrustworthy Answers

LLMs hallucinate. ZGI's RAG engine finds answers from source documents, attaching the original paragraph citation to every response. Verification time drops by 80%+.

### 3. Fragmented Tools & Uncontrolled Costs

Every department uses a different tool; IT maintains dozens of integrations. ZGI's unified model gateway attributes token consumption precisely to each person, department, and application.

## Core Capabilities

| Capability | Description |
|---|---|
| **Enterprise RAG Knowledge Base** | Upload docs to build a knowledge base. Every answer cites the source. Knowledge graph enhanced retrieval. |
| **Visual Agent Orchestration** | Drag-and-drop nodes to build multi-step workflows. No coding required for business users. |
| **Unified Model Gateway** | GPT, Claude, DeepSeek, Qwen — one API to call them all. Hot-swap with zero code changes. |
| **Database & NL2SQL** | Structured data modeling, natural language queries, agents consume business data directly. |
| **Permissions & Cost Control** | Token consumption attributed to person, department, and app. RBAC down to feature level. |
| **Flexible Deployment** | Cloud SaaS ready to go, or self-hosted with data never leaving your network. |

## Open Source

ZGI's core framework is open source under the [Apache 2.0 License](https://github.com/zgiai/zgi). The repository uses a git submodule architecture:

| Directory | Description | Repository |
|---|---|---|
| `api/` | Backend service (Go) | `zgiai/zgi-api` |
| `web/` | Frontend app (React) | `zgiai/zgi-web` |
| `sandbox/` | Code execution sandbox | `zgiai/zgi-sandbox` |
| `plugin-runner/` | Plugin runner service | `zgiai/zgi-plugin-runner` |
| `docker/` | Shared middleware & deployment assets | — |
