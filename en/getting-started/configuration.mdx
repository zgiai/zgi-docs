# Configuration

Learn how to configure ZGI for your specific needs.

## Configuration Files

ZGI uses multiple configuration files:

- **`zgi.config.json`** - Main ZGI configuration
- **`.env`** - Environment variables
- **`tsconfig.json`** - TypeScript configuration
- **`package.json`** - Project dependencies

## zgi.config.json

Main configuration file for your ZGI project:

```json
{
  "name": "my-project",
  "version": "1.0.0",
  "description": "My ZGI project",
  
  "agents": {
    "defaultModel": "gpt-4",
    "temperature": 0.7,
    "maxTokens": 2000,
    "timeout": 30000,
    "retryAttempts": 3,
    "retryDelay": 1000
  },
  
  "database": {
    "type": "postgresql",
    "host": "localhost",
    "port": 5432,
    "database": "zgi_db",
    "pool": {
      "min": 2,
      "max": 10
    }
  },
  
  "knowledge": {
    "embeddingModel": "text-embedding-3-large",
    "chunkSize": 1024,
    "chunkOverlap": 128,
    "vectorStore": "pinecone"
  },
  
  "plugins": {
    "enabled": true,
    "directory": "./plugins",
    "autoLoad": true
  },
  
  "logging": {
    "level": "info",
    "format": "json",
    "file": "./logs/app.log"
  },
  
  "server": {
    "port": 3000,
    "host": "localhost",
    "cors": {
      "enabled": true,
      "origin": "*"
    }
  },
  
  "security": {
    "apiKeyRequired": true,
    "rateLimit": {
      "enabled": true,
      "windowMs": 60000,
      "maxRequests": 100
    }
  }
}
```

## Environment Variables

### Required Variables

```env
# API Keys
ZGI_API_KEY=zgi_sk_your_key_here
OPENAI_API_KEY=sk_your_openai_key
ANTHROPIC_API_KEY=your_anthropic_key

# API Configuration
ZGI_API_URL=https://api.zgi.ai
ZGI_API_VERSION=v1
```

### Optional Variables

```env
# Environment
NODE_ENV=development
LOG_LEVEL=info

# Database
DATABASE_URL=postgresql://user:password@localhost:5432/zgi_db
DATABASE_POOL_MIN=2
DATABASE_POOL_MAX=10

# Server
PORT=3000
HOST=localhost

# Features
ENABLE_PLUGINS=true
ENABLE_KNOWLEDGE_BASE=true
ENABLE_WORKFLOWS=true

# Integrations
SLACK_BOT_TOKEN=xoxb_your_token
GITHUB_TOKEN=ghp_your_token
STRIPE_API_KEY=sk_your_stripe_key
```

## Configuration Best Practices

### 1. Use Environment Variables for Secrets

```json
{
  "database": {
    "password": "${DATABASE_PASSWORD}"
  }
}
```

### 2. Separate Configuration by Environment

```
config/
├── default.json
├── development.json
├── production.json
└── test.json
```

### 3. Validate Configuration on Startup

```typescript
import { validateConfig } from '@zgi/core';

const config = require('./zgi.config.json');
validateConfig(config);
```

### 4. Use Configuration Management Tools

```bash
# Using dotenv
npm install dotenv

# Load environment variables
require('dotenv').config();
```

### 5. Document Configuration Options

```markdown
# Configuration Guide

## agents.defaultModel
The default AI model to use for agents.
- Type: string
- Default: "gpt-4"
- Options: "gpt-4", "gpt-3.5-turbo", "claude-3-opus"
```

## Troubleshooting Configuration

### Issue: Configuration not loading

**Solution**: Check file path and format:

```bash
# Validate JSON
node -e "console.log(JSON.parse(require('fs').readFileSync('./zgi.config.json')))"
```

### Issue: Environment variables not recognized

**Solution**: Ensure `.env` file is in project root:

```bash
# Check .env file
cat .env

# Reload environment
source .env
```

### Issue: Database connection failed

**Solution**: Verify connection string:

```bash
# Test connection
psql $DATABASE_URL
```
