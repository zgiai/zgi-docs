# Quick Start

## Prerequisites

Before you begin, ensure the following:

- A business email (for registration)
- Documents to import (PDF, Word, Excel — or use sample data)
- For self-hosted: Docker environment or Kubernetes cluster

## Four Steps to Your First AI App

<Steps>
  <Step title="Register & Create Workspace">
    Go to [cloud.zgi.cn](https://cloud.zgi.cn) to register, create your enterprise workspace, and invite team members.
  </Step>
  <Step title="Import Data & Build Knowledge Base">
    Upload enterprise documents (contracts, reports, manuals, FAQs) to the knowledge base module. The system automatically handles parsing, chunking, vectorization, and graph construction. Supports PDF, Word, Excel, scanned images, and more.

    <Warning>
    We recommend starting with a small batch (under 10 documents) to validate retrieval accuracy before bulk importing.
    </Warning>
  </Step>
  <Step title="Connect Models & Configure Gateway">
    In the Model Management page, connect your LLM API keys (OpenAI, Claude, DeepSeek, Qwen, etc.), or use ZGI's built-in shared models. Set call priorities and budget limits.
  </Step>
  <Step title="Orchestrate Agents & Publish">
    On the visual workflow canvas, drag and drop nodes to build your AI application logic. Once debugging passes, publish with one click as a Web App or API endpoint.
  </Step>
</Steps>

## Make Your First API Call

For developers, integrate directly via the API:

```bash
curl -X POST https://api.zgi.cn/v1/chat \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zgi-default",
    "messages": [{ "role": "user", "content": "What contracts are expiring in the next three months?" }],
    "knowledge_base_id": "kb_xxxxxx"
  }'
```

Response:

```json
{
  "id": "msg_xxxxxx",
  "content": "Based on the knowledge base, the following contracts expire within three months: ...",
  "citations": [
    { "source": "Procurement_Contract_2025Q4.pdf", "page": 3, "paragraph": "Article 5: Contract Term..." }
  ]
}
```

<Tip>
**Every answer includes source citations.** The `citations` field returns the specific document, page number, and paragraph, so business teams can verify directly — no guessing about sources.
</Tip>

## Local Docker Deployment

For developers who want to run ZGI locally:

```bash
# Clone the repository
git clone https://github.com/zgiai/zgi.git
cd zgi

# One-click startup
make dev-docker
```

`make dev-docker` automatically initializes submodules, copies env templates, generates the root compose file, and starts the full Docker stack.

### Default Service Addresses

| Service | Address | Notes |
|---|---|---|
| **Web Frontend** | `http://localhost:13000` | Console UI |
| **API Backend** | `http://localhost:2678` | REST API |
| PostgreSQL | `localhost:15432` | Primary database |
| Redis | `localhost:16379` | Cache & message queue |
| Weaviate | `http://localhost:18080` | Vector database |
| Neo4j HTTP | `http://localhost:17474` | Knowledge graph |
| Sandbox | `http://localhost:18194` | Code execution sandbox |
| Plugin Runner | `http://localhost:15000` | Plugin runner |

### Windows

Minimum requirement: **Docker Desktop + PowerShell**.

```powershell
# PowerShell
.\dev\start-docker.ps1

# With China mainland mirrors
.\dev\start-docker.ps1 -china
```
