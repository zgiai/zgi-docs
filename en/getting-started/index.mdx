## System Requirements

- **Node.js**: 16.0 or higher
- **npm**: 7.0 or higher
- **Python**: 3.8+ (optional, for some integrations)

## Installation Methods

### NPM (Recommended)
```bash
npm install -g @zgi/cli
```

### Yarn
```bash
yarn global add @zgi/cli
```

### Docker
```bash
docker run -it zgi/cli:latest
```

## First Steps

### 1. Create a Project
```bash
zgi init my-first-project
cd my-first-project
```

### 2. Create an Agent
```bash
zgi create agent my-agent
```

### 3. Run Your Agent
```bash
npm run dev
```
